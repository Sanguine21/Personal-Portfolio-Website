01 — Who I am

Two interests, one way of thinking

I'm a B.Tech Computer Science student at the College of Engineering and Management, Kolaghat, graduating in 2027. Most of what I build falls into two buckets that look unrelated but aren't: interfaces people use directly, and algorithms that let machines navigate on their own.

On the web side, I design and build responsive sites from scratch — HTML, CSS and JavaScript, with an eye for layout and visual clarity. On the algorithms side, I've spent the last several months comparing pathfinding strategies (A*, Theta*, and a terrain-cost-weighted variant I built myself) and extending that work into a ROS2 + Gazebo simulation where a TurtleBot3 explores unmapped terrain on its own.

What connects them is structure. A good webpage and a good path both come down to the same question: what's the clearest, most deliberate way through?

// what am I doing right now
Finishing my 3rd year, applying for front-end development internships (currently Cognifyz Technologies), and extending my robotics exploration project into a more general terrain-aware navigation system.
// why web development
I like that the feedback loop is immediate — you change a line of CSS and you can see, right away, whether it made something clearer or worse. That immediacy is what pulled me from "interested in computers" to "wants to build interfaces people actually enjoy using."
// why pathfinding & robotics
It's the same design instinct applied to a harder problem — instead of arranging pixels, you're arranging decisions a machine has to make with incomplete information. Building the frontier-exploration algorithm from scratch taught me more about problem decomposition than any single web project has.
// how I work
I build in phases with a working version at each stage — the exploration robot project alone went through five distinct phases, each one demoable before I moved to the next. I'd rather ship something small and correct than something large and untested.

ALGORITHMS

Terrain-Weighted Path Planning Simulation

A comparison of three pathfinding strategies on a simulated grid: standard A*, Theta* (any-angle search), and a terrain-cost-weighted version of Theta* that I designed myself to account for uneven ground cost, not just distance. This project is the direct ancestor of the mini pathfinder above.

ROBOTICS · ROS2 · SLAM

Terrain-Aware Autonomous Frontier Exploration

A TurtleBot3 robot in Gazebo autonomously explores a custom-built 3D environment it has no prior map of. It uses SLAM to build a map as it moves, a frontier-ranking algorithm I wrote to decide where to explore next, and A* for path planning between frontiers. Built in five phases, each independently demoable — this project directly extends my terrain-weighted planning work into a real robotic system.
